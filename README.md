# scrapy_parser_pep

Данный парсер производит сбор данных о всех Pep с сайта https://peps.python.org/. Данные группируются по 2 файлам: первый - pep_***.csv, содержит информацию о названии, статусе и коде всех Pep, собранных с главной страницы. Второй - приводит саммари всех пипов по их статусам. Рядом со статусов выводится количество пипов, соотвествующих данному статусу.

Для запуска парсера в терминале выйдете в корневую директорию склонированного проекта и выполните команду: scrapy crawl pep

Удачи в использовании!
