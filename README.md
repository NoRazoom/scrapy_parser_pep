# scrapy_parser_pep

Данный парсер производит сбор данных о всех Pep с сайта https://peps.python.org/. Данные группируются по 2 файлам: первый - pep_***.csv, содержит информацию о названии, статусе и коде всех Pep, собранных с главной страницы. Второй - приводит саммари всех пипов по их статусам. Рядом со статусов выводится количество пипов, соотвествующих данному статусу.

Склонируйте к себе проект: git add https://github.com/NoRazoom/scrapy_parser_pep.git

Создайте виртуальное окружение: python -m venv venv (Для Windows)

Активируйте виртуальное окружение: . venv/Scrips/activate (Для Windows)

Загрузите все зависимости: pip install -r requirements.txt

Для запуска парсера в терминале выполните команду: scrapy crawl pep

Данные отобразятся в файлах в директории /results относительно корня проекта.


Использованные технологии: python, scrapy.
